# member-guide：ご入会のしおり Web 化

紙の「ご入会のしおり」を Google フォームにして、入会手続きの場でスタッフが説明しながらお客様にチェックしてもらう。
回答は自動で Google スプレッドシートに記録され、後々のトラブル防止の証跡にする。

## 仕組み

- 店頭のタブレットでフォームを開き、お客様に操作してもらう
- 章ごとに1ページ。その章の項目を**すべてチェックしないと次へ進めない**
- 最後に同意チェックと署名（氏名の入力）
- 回答日時・お名前・担当スタッフ・チェック内容が、スプレッドシートに1行ずつ自動で残る
- フォーム名とシート名にしおりの版を入れ、どの版に同意したかを区別する

## ファイル

- `gas/createGuideForm.gs`：しおりの内容からフォームと記録シートを自動作成する Google Apps Script
  - 元にしたしおり：Google ドライブの「ご入会のしおり.pdf」（2026-02-02）
  - チェック欄があった4章（必要書類・初回契約金／ご入会の流れ／重要な会員規約／その他の大事なポイント）を収録

## 作成手順

1. https://script.google.com で新しいプロジェクトを作る
2. `gas/createGuideForm.gs` の中身を貼り付け、`STAFF_LIST` にスタッフ名を入れる
3. `createGuideForm` を実行し、ログに出る URL を確認する

## 未決事項

- お客様に控え（回答のコピー）をメールで送るか
- 店頭で使う端末（店舗のタブレット／お客様のスマホ）
