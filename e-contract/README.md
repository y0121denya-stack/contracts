# e-contract：契約書のオンライン化

紙の会員契約書（コピー・製本・紙保管）を電子契約に置き換える取り組み。
既に契約しているマネーフォワード クラウドの電子契約機能（マネーフォワード クラウド契約）を使う方向で検討する。

- 方向性：`../docs/00_direction.md` の「2. 契約書のオンライン化」
