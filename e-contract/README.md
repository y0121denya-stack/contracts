# e-contract：契約書のオンライン化

紙の会員契約書（コピー・製本・紙保管）を MF クラウド契約に置き換える。
入会のしおりの重要部分は、契約書の最後に付ける「重要事項の確認」ページで、お客様に必須チェックしてもらう。

## ファイル

- `important-checks.html`：重要事項の確認ページの原稿（入会のしおり 2026.10版の「重要な会員規約」6項目＋「その他の大事なポイント」5項目）
- `important-checks.pdf`：上の原稿から作った A4・1枚の PDF。各項目の左の □ に MF のチェックボックスを重ねる
- `build-pdf.cjs`：原稿を直したときに PDF を作り直すスクリプト（`node e-contract/build-pdf.cjs`）

元の契約書（会員契約書・会員規約・キャンペーン個別契約書の Excel）としおり（Word）はリポジトリに入れない。原本は社内で管理する。

## 電子契約にする書類

| 書類 | 元ファイルのシート | 備考 |
|---|---|---|
| 会員契約書（頭書） | 会員契約書(両面短辺印刷) | 表面 |
| 会員規約（第1〜35条） | 同上 | 裏面 |
| キャンペーン利用における個別契約書（覚書） | キャンペーン | キャンペーン適用の方のみ |
| 重要事項の確認 | （新規）`important-checks.pdf` | 全員 |

## MF に登録する方法（推奨：テンプレート）

MF クラウド契約の「設定」→「テンプレート」で、PDF とチェック欄の位置を一度登録しておけば、毎回チェック欄を置き直さずに済む。

1. **テンプレート用の PDF を作る**：Excel から空欄の会員契約書・会員規約（とキャンペーン個別契約書）を PDF に書き出し、`important-checks.pdf` を最後に結合する
   - テンプレートは2種類：「通常」＝契約書＋規約＋確認ページ、「キャンペーン」＝そこに個別契約書を追加
2. **テンプレートを作る**：PDF をアップロードし、「入力項目の設定」で次を置く
   - 確認ページの □ 11か所：相手方のチェックボックス・**必須**
   - お客様情報（氏名・住所・生年月日・電話・緊急連絡先など）：相手方のテキスト
   - 会員No・会員種類・オプション・施設利用開始日・変更受付開始日・キャンペーン期間など：自社（あなた）のテキスト
   - お客様の署名（押印）欄
3. **毎回の送信**：テンプレートを選び、お客様の氏名・メールアドレスを入れて、自社側の項目を入力して送信 → お客様がスマホでチェック・入力・署名

**注意**：Excel の数式（年齢・締結日・キャンペーン終了日）はテンプレートでは計算されない。締結日は MF が記録する。キャンペーン期間はスタッフが入力する。
