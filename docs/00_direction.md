# 方向性：入会手続きのデジタル化

対象：パーソナルジム「絆 Style-gym Legame 琴似店」の入会手続き

## 1. 前提

- 会員プランは「通い放題（フリー利用）＋パーソナルトレーニング」を組み合わせた仕組みで、説明が必要。
- 入会の流れは **体験 → その場で入会手続き**。手続きはこの場で必ず完結させる。
- 事前の Web 申込は**作らない**（実績がほとんどなく、プランが複雑なため対面での説明が前提）。
- 法律上必須の書面ではないが、後々のトラブルを防ぐために、会員契約書とご入会のしおりを用意している。
- しおりの全文は Legame 公式アプリで閲覧できる。
- お支払いは目の前で案内する。
  - 口座振替：アプラスの口座振替依頼書（紙・銀行印）
  - クレジットカード：ペイジェントの登録 URL を LINE で送り、お客様が登録

## 2. 契約書のオンライン化（決定）

**MF クラウド契約を使う。**今の MF クラウドの契約で利用できることは確認済み。

- お客様が自分のスマホで署名する。締結済みの契約書は MF に保管され、お客様にも控えが届く。
- スマホやメールが使えないお客様は紙で契約し、顧客管理名簿に「紙での契約書」と記入する。

- プラン：ビジネスプラン。従業員アカウントも追加済み。
- 送信件数：**上限なし・件数による課金なし**（公式 FAQ）。
- 締結完了メールのリンクの有効期限は60日。お客様には契約書 PDF の保存を案内する。

- 従業員は管理コンソールで追加済み。追加による課金はないと判断（CEO 確認、2026-10-27）。

## 3. 重要事項のチェック（決定：契約書の中でチェック）

- 会員契約書の最後に「重要事項の確認」ページ（A4・1枚、11項目）を付け、MF クラウド契約で各項目に必須のチェックボックスを置く。
  - 原稿と PDF：`e-contract/important-checks.html`／`important-checks.pdf`（入会のしおり 2026.10版の「重要な会員規約」「その他の大事なポイント」）
  - 登録手順：`e-contract/README.md`（テンプレート機能でチェック欄の位置を一度だけ登録する）
- チェック結果が締結済みの契約書の中に残り、控えも自動でお客様に届く。紙で契約する場合は同じページを印刷する。
- **要確認**：必須のチェックを入れないとお客様が合意（署名）できないことを、テスト送信で確かめる。
- 予備案（チェックできなかった場合）：Google フォーム（`member-guide/gas/createGuideForm.gs`）

## 4. Web 版しおり（新規の案）

入会のお礼として、しおりを読みやすい Web ページ（漫画風・会話形式など）にして、URL を LINE で送る。

- 公式アプリのしおり（正式版）とは別の、「読みやすい案内」という位置付け。規約の正式な内容は契約書・会員規約が優先。
- 公開ページになるため、Wi-Fi パスワードなど店内限定の情報は載せない。

## 5. 入会手続き当日の流れ（目標）

1. 体験
2. コース・オプションの説明
3. 店内の Wi-Fi に接続してもらう
4. **電子契約**：MF から送信 → お客様がスマホで重要事項にチェックして署名
5. Legame 公式アプリ・公式 LINE・れんらくアプリの登録
6. お支払いの案内（口座振替依頼書の記入、またはペイジェントの URL を LINE で送付）
7. 身分証コピー・写真撮影・お会計・会員証のお渡し
8. 後日（または当日中）：入会のお礼と Web 版しおりの URL を LINE で送る

## 6. 未決事項

- 必須チェックが未入力だと合意できないことのテスト確認
- Web 版しおりの公開場所（Google サイト、GitHub Pages など）と、絵の作り方

## 7. 契約書・しおりの要確認箇所（2026-10-29 照合）

入会のしおり（2026.10版）と会員規約（Excel）を照らし合わせて見つかった点。直すかどうかは担当者が判断する。

1. **第32条（遅刻）**：しおりは「連絡なしで5分経過した場合、権利消化となる場合がある」、規約は「事前連絡なく予約時間に遅れた場合は、いかなる事情があろうとも権利を消化」。5分の猶予が規約にない。確認ページはしおりの文面のまま。
2. **第31条（会員証）**：規約には「IC カード紛失時の再発行手数料 3,300円」が残っているが、しおり 2026.10版では削除されている（入館がれんらくアプリの QR コードに変わったため？）。
3. **第27条3項**：「第29条（事前告知期間）」と書かれているが、事前告知期間は第30条（第29条は緊急事態時の休会・退会）。
4. **第35条（発効）**：「2023年9月8日より発効」のまま。第33条（ピラティス）など後から追加した条文があるなら、改定日の記載が必要か。
5. **しおり第33条の誤字**：「当該当該コースも終了を理由に」→ 確認ページでは規約の文言に合わせて「当該コースが終了したことを理由に」とした。
6. **キャンペーン個別契約書**：PDF に書き出すと契約期間の開始日が「###」になった（LibreOffice で確認）。Excel から書き出す際も列幅を確認する。
