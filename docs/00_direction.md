# 方向性案：初期契約業務のデジタル化

## 1. 現状と課題

| 業務 | 現状 | 課題 |
|---|---|---|
| 契約書 | 紙をコピー・製本し、お客様用と自社用を紙で保管 | 印刷・製本・押印・郵送の手間、保管場所、紛失リスク、検索しにくい |
| 入居のしおり | 紙で発行 | 印刷コスト、改訂が反映しにくい、読んだかどうか分からない |

## 2. 契約書のオンライン化

### 前提（要確認）

- 2022年5月の宅建業法改正で、**重要事項説明書（35条書面）・契約締結時書面（37条書面）は、お客様の承諾があれば電子交付できる**。宅建士の押印も不要になった。
- 承諾は事前に書面か電磁的方法でもらう必要がある。承諾してもらえないお客様には紙で対応する運用も残す。
- 電子化した契約書は電子帳簿保存法に沿って保存する（検索できること、改ざん防止など）。
- 自社の取引形態（仲介、管理、自社物件の貸主など）によって必要な書面が変わるため、対象書類を最初に洗い出す。

### 選択肢

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A. 汎用電子契約サービス** | クラウドサイン、GMOサイン、DocuSign など | 導入が早い。費用が安い。法的な実績が多い | 不動産特有の流れ（重説、承諾取得）は自分たちで運用を組む |
| **B. 不動産特化の電子契約サービス** | 賃貸管理システムや仲介業者向けの電子契約機能（例：いい生活、不動産BB、ITANDI 系など） | 重説の電子交付・IT重説・承諾取得まで流れができている。管理システムと連携しやすい | 費用が高めになることがある。既存システムとの相性次第 |
| C. 自社開発 | 自社で署名・保管の仕組みを作る | 自由度が高い | 法的な有効性・改ざん防止の担保が重く、**おすすめしない** |

**推奨：A か B。**今使っている賃貸管理システムに電子契約機能があれば B を優先して検討し、なければ A から小さく始める。

## 3. 入居のしおりの Web 化

### やりたいこと

- しおりを Web で閲覧できる
- 重要事項の箇所ごとに「読んだ」チェック欄
- チェックしないと次へ進めない
- 誰が・いつ・どの版を確認したかを記録する

### 選択肢

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A. Google フォーム | セクションごとに必須チェックボックスを置く | すぐ作れる。無料。回答がスプレッドシートに残る | 見た目の自由度が低い。図や長文は読みにくい |
| **B. 自作の Web ページ（小規模）** | しおり本文＋必須チェック＋確認ログ保存。入居者ごとに専用 URL を発行 | 見た目・操作性を作り込める。版管理・物件ごとの出し分けができる | 開発と運用（ホスティング）が必要 |
| C. 既存 SaaS の入居者アプリ | 管理会社向け入居者アプリのしおり機能など | 保守不要 | 「チェックしないと進めない」が実現できるかは製品次第 |

**推奨：A でまず試し、本番は B。**
Google フォームで 1 物件分を作って現場とお客様の反応を見て、要件が固まったら B に移る。B は、本文を Markdown で管理し、確認ログ（入居者 ID・項目・日時・版）を保存する構成が扱いやすい。

### 注意

- しおりの「重要事項」チェックは、**宅建業法の重要事項説明の代わりにはならない**。重説は宅建士が別途行う。
- 「読んだ」記録はトラブル時の証跡になるので、どの版の文面に同意したかを必ず残す。

## 4. 進め方（段階案）

| 段階 | 内容 | 目安 |
|---|---|---|
| 0. 現状整理 | 契約書・しおりの種類、件数、関係者、今のシステムを洗い出す | 1〜2週 |
| 1. しおり試作 | Google フォームで 1 物件分を作り、社内で試す | 1〜2週 |
| 2. 電子契約の選定 | 2〜3 サービスを比較し、無料トライアルで 1 件試す | 2〜4週 |
| 3. 本番運用 | 電子契約を本番導入（紙対応も併用）。しおりを Web 版に移行 | 1〜2か月 |
| 4. 自動化 | 契約完了 → しおり URL を自動送付 → 未確認者へリマインド、などをつなぐ | 以降 |

## 5. 未決事項（確認したいこと）

1. 取引形態：仲介・管理・自社物件の貸主のどれか（複数可）
2. 月あたりの契約件数
3. 今使っている賃貸管理システム・顧客管理ツール
4. 契約書の種類（普通借家・定期借家・駐車場など）と、ひな形の数
5. しおりの分量、物件ごとに内容が違うか
6. お客様への連絡手段（メール・LINE・SMS など）
7. 予算感（月額サービス費・開発費）
