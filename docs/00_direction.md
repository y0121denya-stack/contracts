# 方向性：入会手続きのデジタル化

対象：パーソナルジム「絆 Style-gym Legame 琴似店」の入会手続き

## 1. 前提

- 会員プランは「通い放題（フリー利用）＋パーソナルトレーニング」を組み合わせた仕組みで、説明が必要。
- 入会の流れは **体験 → その場で入会手続き**。手続きはこの場で必ず完結させる。
- 事前の Web 申込は**作らない**（実績がほとんどなく、プランが複雑なため対面での説明が前提）。
- 法律上必須の書面ではないが、後々のトラブルを防ぐために、会員契約書とご入会のしおりを用意している。
- 既に契約しているもの：マネーフォワード（MF）クラウド。

## 2. 契約書のオンライン化

**方針：MF クラウドの電子契約機能（マネーフォワード クラウド契約）を使う。**

- その場での流れ（案）：スタッフが MF から契約書を送信 → お客様が自分のスマホでメールを開いて同意・署名 → 締結済みの契約書は MF に自動で保管され、お客様にも控えが届く。
- 紙のコピー・製本・保管が不要になる。

**要確認**
- 今の MF クラウドのプランでクラウド契約が使えるか、送信件数の上限・追加費用（プランによって含まれる範囲が違う）。
- アプラスの口座振替依頼書（銀行印が必要）は紙のまま残る可能性が高い。Web で口座登録できる方法があるかをアプラスに確認する。
- メールアドレスやスマホを使えないお客様向けに、紙での契約を残すか。

## 3. ご入会のしおりの Web 化

**方針：Google フォームで作り、回答を Google スプレッドシートに自動で記録する。**

- 店頭のタブレットで、スタッフが説明しながらお客様にチェックしてもらう。
- 章ごとにページを分け、その章の項目を全部チェックしないと次へ進めない。
- 最後に同意チェックと署名（氏名の入力）。
- 回答日時・お名前・担当スタッフ・チェック内容がスプレッドシートに自動で残る。フォームとスプレッドシートの連携は Google の標準機能なので、追加の仕組みはいらない。
- フォームは、現在のしおり PDF（2026-02-02）の内容から、スクリプトで自動作成する（`member-guide/gas/createGuideForm.gs`）。

## 4. 入会手続き当日の流れ（目標）

1. 体験
2. コース・オプションの説明
3. **しおりフォーム**：説明しながらお客様がチェック → 記録シートに自動保存
4. **電子契約**：MF から送信 → お客様がスマホで署名
5. 口座振替依頼書（紙）・身分証コピー・写真撮影・アプリ登録
6. お会計・会員証のお渡し

## 5. 次の一手

1. Google フォームを作り、スタッフ同士で試す
2. MF クラウド契約が今のプランで使えるかを確認し、会員契約書のひな形で1件テスト送信する
3. 両方を当日の流れに組み込み、紙と並行して運用を始める
